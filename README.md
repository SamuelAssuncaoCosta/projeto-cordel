# Projeto Cordel

Projeto desenvolvido durante meus estudos de HTML5 e CSS3, com o objetivo de praticar a construção e a estilização de páginas web.

## 📖 Sobre o projeto

Uma página dedicada à apresentação de um cordel, utilizando elementos visuais para valorizar a leitura e proporcionar uma experiência diferenciada.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 💡 Conceitos praticados

- Estruturação de páginas com HTML
- Estilização de textos e elementos com CSS
- Utilização de imagens de fundo
- Aplicação de fontes personalizadas
- Controle de espaçamento e dimensões
- Efeitos visuais e organização do conteúdo

## 🎯 Objetivo

Praticar os conhecimentos de HTML5 e CSS3, explorando diferentes recursos de estilização e apresentação de conteúdo.
